# 花間 · 空気感のある花あしらい

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

花材を置き、枝葉を剪定し、花器と光を選びながら作品をつくるウェブアトリエです。[flowerist.org](https://flowerist.org/) でお試しください。

## 作品をつくる

1. 花材の種類・色・名前から選びます。色の絞り込みは同じ花材のすべての姿を調べ、一致する花色の素材を表示します。
2. 花器を選び、キャンバスに花材を置きます。移動、回転、拡大縮小、反転、レイヤーの前後調整ができます。スマートフォンでは2本指で回転・拡大縮小できます。花をドラッグすると茎は花器の口を支点に向きを変え、根元の点をドラッグすると一枝ごと動きます。花器から外れた茎には印が付き、まとめて挿し直せます。切り分けた一片も実際の切り口から花器に戻ります。
3. 一枝を切って二つの独立したレイヤーに分けたり、消しゴムで細部を整えたりできます。茎の長さと花材の大きさは別々に調整できます。
4. 作品に名前をつけ、光と背景を選びます。「光」では朝の光・昼の光・夕暮れ・月明かりの窓の光を加えられ、壁に落ちる花の影も調整に合わせて動きます。そのうえで画像生成用パックを書き出します。下書きと短いプロンプトをお使いの画像生成ツールに渡し、完成画像を作品集に読み込めます。

花材はすべて実寸で現れ（キャンバスは100 cm四方）、大きさは実物の80〜125%の範囲で調整します。描き足す茎は種類ごとの実際の太さ・色・切れる長さに従い、花器の口・剣山・穴に挿さり、水盤には水面が見えます。新しい花材は真・副・控の位置に前後も自動で収まり、ツールバーの「いけばな比例ガイド」は選んだ花器に合わせて三本の線と目安を描きます（直立・傾斜、左右）。「この線に合わせる」で一度に整えられます。空のキャンバスでは三つの始め方を示します。

キャンバスはトラックパッドのピンチ、Ctrl+スクロール、脇のボタンで拡大でき、スマートフォンでは余白のダブルタップで拡大します。Shift+スクロールで選んだ茎を回転、Alt+スクロールで大きさを変えます。ライブラリの「旬」は今の季節で絞り込み、「最近」は同じ姿をもう一本加えます。

キャンバスには花材を最大24レイヤー配置できます。現在のライブラリは **78種類・171姿の花材、31点の花器**を収録。インスピレーションには **50組**の編集可能な作例があり、量感・季節・流派の発想から探して、そのままアトリエで手を加えられます。画面は中国語・英語・日本語に対応しています。

## ローカルで動かす

静的サイトのため、ウェブ用パッケージのインストールは不要です。

```sh
python3 -m http.server 4173 --directory dist
```

`http://localhost:4173/` を開いてください。自動チェックは次のコマンドで実行できます。

```sh
node --test tests/*.test.mjs
```

`dist/` にサイトと実行に必要な素材、`tests/` に主な機能と素材の確認、`docs/` に出典と制作記録があります。サイトはローカルの素材原本アーカイブに依存しません。

## 保存・画像生成・共有

編集中の下書きはブラウザの localStorage、作品集は IndexedDB に保存されます。ブラウザのデータを消すと保存内容も失われます。「マイ作品」の「すべての作品をバックアップ」で、下書き・プレビュー・写真をまとめた .zip をダウンロードでき、「バックアップから復元」でどのブラウザにも戻せます（同じ作品は新しいほうを残します）。下書き1点は `composition.json` としても保存できます。下書き共有リンクには構図・剪定・窓の光の情報が含まれますが、生成した完成画像は含まれません。リンクを開くとまず作品カードが表示され、続きをつくるか作品集に残すかを選べます。手を加えた作品には元の作品名が添えられます。作例にはそれぞれのリンク（`/?study=<id>`）があり、「レシピ」では買う花材と切る長さをまとめたカードを作れます。

画像生成用パックではスマホ壁紙（9:16、目安 1440 × 2560）、MacBook 壁紙（16:10、目安 2880 × 1800）、正方形の写真を選べます。ChatGPT または Gemini · Nano Banana を選び、下書きとプロンプトを渡して、完成した写真を作品集に取り込めます。プロンプトは自然な光と花色、質感と余白を大切にし、花材、主な構成、花器、全体の光を保ちながら物理的に自然に整えます。正方形の下書きは構図の参考で、壁紙比率に引き伸ばしません。パックには `draft.png`、任意の `composition-guide.png`、`prompt.txt`、`composition.json` と3言語の説明が入ります。画素数は目安で、実際の出力は使用するツールによります。サイト自体は画像生成 API を呼び出さず、API キーも含みません。
