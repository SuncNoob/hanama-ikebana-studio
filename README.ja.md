# 光と花 · HANAMA

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

花材を置き、枝葉を剪定し、花器と光を選びながら作品をつくるウェブアトリエです。[flowerist.org](https://flowerist.org/) でお試しください。

## Unity WebGL アトリエ

花材を引くと、根元を固定したまま茎が自然に曲がり、花冠は形を保って枝と一緒に動きます。根元の点で一枝を移動し、茶色と緑のハンドルで回転・拡大縮小します。スマートフォンでは2本指にも対応しています。8本の等長セグメントを制約付き FABRIK と花材ごとの曲げ上限で制御し、そよ風と操作の余韻を減衰させます。枝の曲がりは剪定・反転・元に戻す操作・保存後も引き継がれます。

主な素材ライブラリは **写真の質感を持つ透明な花材12点、背景3点、花器3点**です。1枚のオリジナル生成静物画を共通の基準に、左上からの広い光、花びらの透け感、釉薬の反射をそろえたAI生成画像であり、実物を撮影した写真ではありません。背景はブラッシュ、暖かなアイボリー、プラムの3種類。最初の作品は杏色のバラ、ボルドー色の椿、桜、カラー、ユーカリを深い釉の丸壺に合わせています。「追加」は新シリーズを表示し、「もっと見る」に過去の素材を残しています。独立したIDにより既存作品は元画像で開け、編集できる作例50組も使えます。元のPNG・実行用WebP・正確なプロンプトは `dist/assets/editorial/art-direction.json` と `environment-art-direction.json` に記録しています。

主な入口を「追加」「光と景」「作品」にまとめ、はさみと消しゴムをキャンバスのそばに置きました。細かな調整は花材を選んでから開きます。光と景は窓辺・曇り・夕映え・月影の4種類。花器の外にも自由に花材を置け、挿し直しを繰り返し促しません。保存・共有・書き出しに加え、「この瞬間を撮る」で現在の Unity 画面を1600 × 1600 PNGに保存できます。そよ風、任意の音、システムの視差効果を減らす設定に対応しています。

操作中の描画バッファは長辺をデスクトップ720画素、狭い画面640画素に制限し、写真は別の1600画素で出力します。描画器の変更時に598 × 598画素の同条件で測ったソフトウェアGPUの2つの比較では、平均フレームスケジューリング間隔が約21〜26%改善しました。これは今回の写真風花材12点を導入する前の測定で、新シリーズ全体や実機の一定フレームレートを示すものではありません。ソースは `unity/HanamaUnity`、実装・測定条件・ビルド手順は [UnityWebGL.md](docs/UnityWebGL.md) にあります。

## 作品をつくる

1. 「追加」から厳選花材を選ぶか、全素材を種類・色・名前で探し、花器を選びます。
2. 花先で茎を曲げ、根元で配置します。ハンドルや2本指で回転・大きさを調整し、細かな設定は選択後の「調整」で開きます。
3. はさみで局部のつながりを切り、独立した一片にしたり、消しゴムで細部を整えたりします。「曲げを戻す」で枝の曲がりを取り消せます。
4. 「光と景」で環境を選び、「作品」で名前をつけて保存・撮影します。AI生成用パックなどの補助操作は展開項目にまとめています。

キャンバスは100 cm四方を表し、花材は実寸に合わせた範囲で調整します。茎の長さは別に変えられ、最大24レイヤーを配置できます。既存の姿、花器、剪定、レシピ、共有、バックアップ、読み込み機能は引き続き利用できます。画面は中国語・英語・日本語に対応しています。

## ローカルで動かす

静的サイトのため、ウェブ用パッケージのインストールは不要です。

```sh
python3 -m http.server 4173 --directory dist
```

`http://localhost:4173/` を開いてください。自動チェックは次のコマンドで実行できます。

```sh
node --test tests/*.test.mjs
```

`dist/` にサイトと実行に必要な素材、`tests/` に主な機能と素材の確認、`docs/` に出典と制作記録があります。サイトはローカルの素材原本アーカイブに依存しません。

## 保存・画像生成・共有

編集中の下書きはブラウザの localStorage、作品集は IndexedDB に保存されます。ブラウザのデータを消すと保存内容も失われます。「マイ作品」の「すべての作品をバックアップ」で、下書き・プレビュー・写真をまとめた .zip をダウンロードでき、「バックアップから復元」でどのブラウザにも戻せます（同じ作品は新しいほうを残します）。下書き1点は `composition.json` としても保存できます。下書き共有リンクには構図・剪定・窓の光の情報が含まれますが、生成した完成画像は含まれません。リンクを開くとまず作品カードが表示され、続きをつくるか作品集に残すかを選べます。手を加えた作品には元の作品名が添えられます。作例にはそれぞれのリンク（`/?study=<id>`）があり、「レシピ」では買う花材と切る長さをまとめたカードを作れます。

画像生成用パックではスマホ壁紙（9:16、目安 1440 × 2560）、MacBook 壁紙（16:10、目安 2880 × 1800）、正方形の写真を選べます。ChatGPT または Gemini · Nano Banana を選び、下書きとプロンプトを渡して、完成した写真を作品集に取り込めます。プロンプトは自然な光と花色、質感と余白を大切にし、花材、主な構成、花器、全体の光を保ちながら物理的に自然に整えます。正方形の下書きは構図の参考で、壁紙比率に引き伸ばしません。パックには `draft.png`、任意の `composition-guide.png`、`prompt.txt`、`composition.json` と3言語の説明が入ります。画素数は目安で、実際の出力は使用するツールによります。サイト自体は画像生成 API を呼び出さず、API キーも含みません。
