## 剪枝、长度与草稿保存

圈选剪枝和细部擦除仅作用于当前选中的一枝。剪口以原始素材的归一化坐标保存，再用于透明度擦除；原图文件不被修改。同一剪枝结果同时用于编辑画布、草稿 PNG、作品集预览与草稿分享卡，经过旋转、镜像或伸缩后仍与该枝对应。每次剪枝可撤销、重做，也可恢复整枝。

枝梗长度独立于花材大小，范围为原长的 **60–240%**。伸缩作用于每款素材设定的下部枝梗段，上部花叶保持原有大小；裁短仍可独立调整。款式、剪口、长度、布局和生成自由度均写入 v2 草稿 JSON，重新导入后可以继续编辑；旧版 v1 草稿仍可打开。

## 可选花器

现有 **23 款**花器。原有 12 款 GPT Image 日式透明花器包括高颈细瓶、高细筒、矮胖圆瓶、矮圆钵、方形直筒、方形矮器、青釉水盘、深蓝椭圆盘、暖沙陶盆、铁锈粗陶筒、浅灰扁圆瓶及深绿高肩瓶。本轮再以 9 次独立 GPT Image 请求新增三组原创透明花器：英式奶油陶壶、旧银高脚盆与砂岩庭院瓮；法式美第奇杯、炭黑高脚盆与雾蓝套盆；现代烟灰玻璃柱瓶、拉丝钢双口环形器与洞石长槽器。网页按日式、英式、法式、现代筛选。

每款按自身比例显示，瓶口区域逐一标定；环形钢器记录双插口，洞石长槽记录长方形口部。换器按新旧主要插入点的差值平移现有枝条，导出的草稿与编辑器使用相同花器尺寸。

固定结构由花器元数据自动决定：水盘与宽浅器采用黄铜或黑化黄铜剑山，高脚盆可采用花艺网，宽口瓮与套盆采用藏在口沿下的环保花泥，圆筒采用内藏网格或十字撑，窄口瓶依靠瓶口支撑，双口现代器使用一体插口。只有现实中应当看见的结构才画入画布；隐藏结构只进入物理说明与 Prompt。固定结构服务于真实插入关系。生成时保留花材数量与主要设计，允许局部调整插点、角度、遮挡和接触阴影，使枝条确实进入花器并获得支撑。

原日式花器生成记录见 [花器图集 1](vessel-atlas-1-prompt-v2.txt)、[花器图集 2](vessel-atlas-2-prompt-v2.txt) 与 [v2 花器元数据](vessel-metadata-v2.json)。本轮 9 款素材与共同生成约束见 [花器扩展 v3](vessel-expansion-v3.md)，完整口部和固定结构数据见 [v3 花器元数据](vessel-metadata-v3.json)。

## 从草稿到生成作品

创作包由网页从实际摆放状态实时产生，包括：

1. `draft.png`：1600×1600 的构图图像，保留实际花材款式、剪枝和长度调整，不带界面和选择框。
2. `composition-guide.png`：用实际剪枝、镜像和枝梗长度产生的可选轮廓参考，仅辅助理解大致前后关系，不约束生成图照描端点。
3. `prompt.txt`：保留用花与花朵数量、主要构图、花器和整体光感，允许小幅修正枝条曲线、花面、局部空间与固定结构，让设计成为可实际搭建的插花。局部阴影与反光随结构重算。
4. `composition.json`：可重新导入的完整 v2 草稿，包含剪枝记录、枝梗长度与生成自由度。
5. `readme.txt`：上传、生成、导入、分享的步骤。

三种生成自由度：

- **小幅自然重整（默认）**：保留设计身份，小幅整理枝条、花面、前后空间和瓶口插入关系。
- **适度花艺润色**：在同一构图内，对花面、枝条节奏和深度多做一点调整，仍不减花或大幅改构图。
- **最小修正**：最接近草稿，但必须修复不合理插入、悬空和穿插，而非逐像素复制。

网页不伪造生成结果，也不自动调用付费图片 API。用户将草稿和提示词一起提交给自己的 GPT Image 工具，随后导入成品。生成后需检查是否保留了自己的用花、意境与设计重点。

可编辑分享链接保留构图、剪枝、枝梗长度和生成自由度，不包含成品图片。支持的浏览器使用 gzip 压缩后写入 `#draft2=`；旧版 `#draft=` 链接仍可导入。链接过长时改用 JSON 草稿文件；无法解压链接的浏览器也可通过 JSON 恢复。分享链接不会自动公开上传作品，接收者仍需有权访问工房。
