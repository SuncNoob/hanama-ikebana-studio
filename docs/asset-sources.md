## 剪枝、长度与草稿保存

圈选剪枝和细部擦除仅作用于当前选中的一枝。剪口以原始素材的归一化坐标保存，再用于透明度擦除；原图文件不被修改。同一剪枝结果同时用于编辑画布、草稿 PNG、作品集预览与草稿分享卡，经过旋转、镜像或伸缩后仍与该枝对应。每次剪枝可撤销、重做，也可恢复整枝。

枝梗长度独立于花材大小，范围为原长的 **60–240%**。伸缩作用于每款素材设定的下部枝梗段，上部花叶保持原有大小；裁短仍可独立调整。款式、剪口、长度、布局和生成自由度均写入 v2 草稿 JSON，重新导入后可以继续编辑；旧版 v1 草稿仍可打开。

## 从草稿到生成作品

创作包由网页从实际摆放状态实时产生，包括：

1. `draft.png`：1600×1600 的构图图像，保留实际花材款式、剪枝和长度调整，不带界面和选择框。
2. `prompt.txt`：根据选中的花材与自然色系、用户意境、花器、场景和生成自由度组织创作提示。草稿用于表达创意；提示词允许重新组织有生命感的枝条、花面和三维空间，并要求保留剪枝形成的疏朗感。
3. `composition.json`：可重新导入的完整 v2 草稿，包含剪枝记录、枝梗长度与生成自由度。
4. `readme.txt`：上传、生成、导入、分享的步骤。

三种生成自由度：

- **自然重构（默认）**：保留花材身份、主要姿态、配色、非对称关系和留白，允许调整枝条曲线、花面朝向、间距、重叠和深度。
- **大胆再创作**：保留植物类别、主要配色、花器特征与情绪意图，允许更充分地重组枝条路径、高度、平衡与空间。
- **贴近布局**：接近主要方向、大小层次与留白，同时修正僵硬连接、不合理交叉和拼贴比例，保留自然变化。

网页不伪造生成结果，也不自动调用付费图片 API。用户将草稿和提示词一起提交给自己的 GPT Image 工具，随后导入成品。生成后需检查是否保留了自己的用花、意境与设计重点。

可编辑分享链接保留构图、剪枝、枝梗长度和生成自由度，不包含成品图片。支持的浏览器使用 gzip 压缩后写入 `#draft2=`；旧版 `#draft=` 链接仍可导入。链接过长时改用 JSON 草稿文件；无法解压链接的浏览器也可通过 JSON 恢复。分享链接不会自动公开上传作品，接收者仍需有权访问工房。
