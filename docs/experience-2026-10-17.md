# Creation, image handoff and contemporary studies

- The header plus reuses the existing new-canvas action. A native modal offers Save & create, Create without saving, and Cancel. Saving awaits the IndexedDB transaction; an error retains the active document and displays an in-dialog error. Closing or cancelling changes nothing. Existing saved works and drafts are never migrated into the new default.
- AI image opens the generation dialog directly, including a clear draft + prompt handoff explanation. The dialog lives in the browser top layer; its header remains fixed while the content scrolls within the viewport. Empty compositions also receive an explicit dialog. Generation still happens in the selected external image tool.
- The eraser icon is centred on its ring instead of offset to the upper right (previously lifted farther for touch). The ring uses the native canvas bounds and converts pointer coordinates into the overlay's actual local box, including stage borders and CSS zoom. Its translucent icon leaves the erased pixels visible. Native cut data, alpha preview, cancellation and history stay intact.
- Six contemporary studies lead the inspiration library, with a Contemporary filter and matching 600px WebP previews rendered through the actual compositor. All 50 previous studies remain, for 56 total. The default is White Space: two callas and silver foliage at separate heights. Materials retain their measured sizes; only lower stems are length-adjusted within botanical limits.

Validation: 247 unit checks passed, one existing skip; five real Unity WebGL eraser cases cover desktop, flipped/rotated, bent, and touch input, including preview/commit consistency and undo/redo. Desktop zoom checks cover 100%, 125% and 150%, with the ring and icon within 0.2 CSS px of the pointer and native hit points within the render buffer's pixel quantization. UI checks cover Chinese/English/Japanese at five desktop/phone/landscape sizes, modal bounds, saved record contents, cancellation, storage failure recovery and the new modern filter.
