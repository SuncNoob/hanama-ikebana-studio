# The Flower Book — original photographic materials

Source: the user-supplied Rachel Siegfried / DK PDF (228 PDF pages). `book-photo-catalog.json` records all 60 botanical profile spreads: `page` is the PDF page; `pages` are printed page numbers.

The library now presents all 60 original botanical profile photographs, including 34 grouped/multistem poses. The embedded facing-page photographs were joined, reduced to a working height of 1200 pixels, separated from page typography and white paper, cropped, and encoded as transparent WebP. Flower faces were not regenerated or recolored. The source groups remain one material layer and can be pruned. Their original short stems remain where the book cropped them; these assets do not claim AI-completed stems. The user permits targeted completion if necessary.

The six earlier AI-adapted specimens remain registered for saved-draft compatibility, but are no longer offered as default new-library materials. Original GPT Image variants remain available alongside the photographs. The new photographs have separate `photo-` IDs, so saved draft geometry and old assets remain intact.

Only isolated working assets and small thumbnails ship with the site. The PDF, full page scans, contact sheets and extraction intermediates are not published. Rights to the book photography remain with its respective owners; this provenance record does not assert a new license.

Prompt inventory explicitly identifies grouped specimens as groups including all visible blooms, rather than counting a whole group as a single flower.
