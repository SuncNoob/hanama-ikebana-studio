# 光影插花 · HANAMA

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

一个可亲手摆放花材、修剪枝叶、调整花器与氛围的插花网页。在线体验：[flowerist.org](https://flowerist.org/)。

## Unity WebGL 插花台

画布由 Unity WebGL 渲染，拉动花材可弯出自然曲线，根部保持固定，花冠整体随枝移动；拖根部圆点移动整枝，棕色与绿色手柄分别旋转和缩放，手机支持双指操作。每枝采用八段等长骨架、六轮受约束的 FABRIK 求解、相邻曲率平滑与更宽的花材专属弯曲范围，以不依赖帧率的跟随响应让拖动更柔顺。弯枝时根部与节长保持固定，花冠保持整体形状；松手保存当前可见角度。花头旋转时，最初抓住的位置继续跟随指针，抓在花瓣边缘也能保持跟随。微风和拖动惯性由阻尼控制，剪口、镜像、撤销和重新打开作品都会保留枝形。

完整素材库默认提供 **78 类花材、198 种姿态（含 11 类叶材、23 种叶材姿态）、35 只花器和 9 种背景**，可直接按类型、颜色或名称浏览。12 款新摄影风格花材优先作为封面展示，历次花材、叶材和花器同样可直接选用，无需切换「更多花材」；独立 ID 保留旧作品的原图，50 组可编辑搭配也继续可用。9 种背景包括 3 幅新摄影环境、3 幅此前的花间环境和素纸、青灰、墨夜 3 种经典背景。新摄影系列以同一张原创生成静物为艺术基准，统一上左侧宽光、花瓣透光与釉面反射，是 AI 摄影风格图，并非拍摄实物所得。默认构图以杏色玫瑰、酒红山茶、樱枝、马蹄莲和尤加利搭配深釉圆瓶。新系列的原始 PNG、运行 WebP 与完整生成提示词见 `dist/assets/editorial/art-direction.json` 和 `environment-art-direction.json`。

首屏以花与画布为中心，剪刀、橡皮、枝长、翻转、复制、图层、撤销和重做八个常用工具始终在画布旁，手机采用两排完整按钮。「枝长」一键打开滑杆，只改变下段枝干长度，保持花头尺寸不变。剪切与擦除无需展开详情或点「完成」，再点当前工具即可退出。「光景」直接列出全部背景和光照选项，可独立选择并调整光向、浓淡与微风。标题、保存与高级调整收在「作品」里，可保存、分享、导出，也可「拍下这一刻」下载当前 Unity 画面（1600 × 1600 PNG）。花器之外的花枝可自由摆放，不会持续提醒插回；可选音效和系统减少动态效果设置均有对应处理。

交互画面的像素缓冲最长边限制为桌面 720、窄屏 640，独立的照片输出仍为 1600。渲染器调整阶段以相同 598 × 598 像素缓冲进行的两组软件 GPU 对照中，平均帧调度间隔改善约 21–26%；该数据早于本轮 12 款摄影风格素材，不代表新素材全量测试或所有设备的恒定帧率。Unity 源项目在 `unity/HanamaUnity`，实现、测量条件与构建说明见 [UnityWebGL.md](docs/UnityWebGL.md)。

## 开始创作

1. 打开「花材」，按类型、颜色或名称浏览完整花材和叶材库，再选择花器。
2. 拉动花头弯枝，拖根部安排位置，用手柄或双指调整方向与大小；详细参数位于「作品 → 更多 → 调整」。
3. 点首屏「枝长」并拖动滑杆，单独拉伸下段枝干；花头大小保持不变。用相邻的撤销、重做按钮回退或恢复编辑。
4. 用首屏「翻转」镜像花材、「复制」添加一份，用「图层」选择花枝并调整前后顺序。
5. 用剪刀切开局部连接，分出可独立移动的花枝，或用橡皮修整细节；再次点击当前工具退出。「还原枝形」可取消弯曲。
6. 在「光景」直接选择全部背景与光照，在「作品」命名、保存或拍照。AI 生图包等辅助操作收在展开项中。

画布按 100 cm 见方计算，花材大小按真实比例限定，枝梗长度可单独调整。画布最多容纳 24 层花材；原有姿态、花器、剪枝、配方、分享、备份与导入功能继续可用。界面支持中文、英文和日文。

## 在本地运行

只需静态文件服务器，无需安装网页依赖：

```sh
python3 -m http.server 4173 --directory dist
```

然后打开 `http://localhost:4173/`。运行自动检查：

```sh
node --test tests/*.test.mjs
```

`dist/` 包含网站及运行所需素材，`tests/` 是关键交互与素材检查，`docs/` 保存素材来源和创作记录。网站不依赖本地的原始素材归档。

## 保存、生成与分享

当前草稿保存在浏览器的 localStorage，作品集保存在 IndexedDB；清理浏览器数据会删除这些本机内容。「我的作品」里的「备份全部作品」会下载一个包含全部草稿、预览和成品照片的 .zip，在任意浏览器用「从备份恢复」导回（同一作品保留较新的版本）；单幅草稿也可下载 `composition.json`。分享草稿链接会携带构图、剪枝与窗光数据，不包含生成成品图片；对方打开时先看到作品卡片，再选择继续创作或收进作品集，改作会注明出处。每组灵感搭配都有自己的链接（`/?study=<id>`）。「配方」生成一张写明要买什么、各剪多长的配方卡。

生图包可选择手机壁纸（9:16，参考 1440 × 2560）、MacBook 壁纸（16:10，参考 2880 × 1800）或方形照片，再选择 ChatGPT 或 Gemini · Nano Banana。对话框引导上传草稿、复制 Prompt、打开所选工具，并将成品导回作品集。Prompt 参考高品质花卉摄影的自然光、真实色彩和留白，保留用花、主要结构、花器与整体光感，同时允许符合物理逻辑的整理；方形草稿只是参考，不会被拉伸成壁纸。生图包包含 `draft.png`、可选的 `composition-guide.png`、`prompt.txt`、`composition.json` 和三语说明。标注的像素是目标，实际输出取决于所选生图工具。网页本身不调用图片生成 API，也不包含 API 密钥。
