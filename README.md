# 花间 · 氛围插花

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

一个可亲手摆放花材、修剪枝叶、调整花器与氛围的插花网页。在线体验：[flowerist.org](https://flowerist.org/)。

## 开始创作

1. 在花材库按类型、颜色或名称挑花。颜色筛选会检查每种花的所有姿态，并展示匹配花色的款式。
2. 选择花器，将花材拖到画布上。可旋转、缩放、翻转、改变前后层次；手机上可双指旋转与缩放。拖动花头时花枝绕瓶口转向，拖根部圆点才整枝移动；离开花器的花枝会标出圆圈，可一键全部插回，剪下的一段也以真实剪口插回花器。
3. 使用剪刀把一枝分成两个可独立移动的图层，或用细部擦除修整。枝梗长度和花材大小可分别调整。
4. 为作品命名，设置光与景，再下载生图包。将草稿图与简短 Prompt 交给自己的图片生成工具，完成后可把成品导回作品集。

画布最多容纳 24 层花材。素材库现有 **78 类、171 款花材姿态**和 **31 款花器**；灵感手帖提供 **50 组**可编辑搭配，支持按疏密、季节与流派取意查找，并可直接打开继续创作。界面可切换中文、英文、日文。

## 在本地运行

只需静态文件服务器，无需安装网页依赖：

```sh
python3 -m http.server 4173 --directory dist
```

然后打开 `http://localhost:4173/`。运行自动检查：

```sh
node --test tests/*.test.mjs
```

`dist/` 包含网站及运行所需素材，`tests/` 是关键交互与素材检查，`docs/` 保存素材来源和创作记录。网站不依赖本地的原始素材归档。

## 保存、生成与分享

当前草稿保存在浏览器的 localStorage，作品集保存在 IndexedDB；清理浏览器数据会删除这些本机内容，请下载可恢复的 `composition.json` 备份。分享草稿链接会携带构图和剪枝数据，不包含生成成品图片。

生图包包含 `draft.png`、可选的 `composition-guide.png`、`prompt.txt`、`composition.json` 和使用说明。Prompt 保留用花、主要结构、花器与整体光感，允许小幅修正枝条和插入关系，使结果更自然。网页本身不调用图片生成 API，也不包含 API 密钥。
